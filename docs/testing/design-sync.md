# Design sync (decision 42) — test checklist

No migration. Compare each screen on your phone with the canvas
(https://claude.ai/artifact/42YP5UcaQKWnfQdERRgLcc). Check in **both** Dark and Light.

## 1. Tab bar
- [ ] The bar is narrower (44 pt in from each side) and sits a little higher than before.
- [ ] The **+** is a solid blue circle with a dark plus and a soft blue glow; the gap between
      it and the tabs is wider.
- [ ] Tab labels are slightly lighter (semibold). Switching tabs is instant.

## 2. Type and spacing everywhere
- [ ] Tab titles (Your crew, Rankings, Profile) are bigger (34 pt).
- [ ] Big numbers — a workout's result, the review total, Rankings' volume card, PB values —
      are all the same 34 pt bold, with normal letter spacing.
- [ ] Small capital labels (DISTANCE, TOP PERSONAL BESTS, section headers) are lighter and less
      widely spaced.
- [ ] Body text is a touch larger; nothing is cut off or overlapping (check long names, the
      feed card's numbers, Test results tiles, the Volume list).

## 3. Pushed screens
- [ ] Settings, Find rowers, Personal bests, PB history, Your crew, Manage club, Create a club,
      Find a club, a rower's profile, Comments, a test board, Log workout and Review session:
      the title is **centred** at the top, with the round back button on the left.
- [ ] A club test's board (as an admin) has the red bin on the right; Log workout has **Help**.

## 4. Settings
- [ ] Section headers have more space above them.
- [ ] **Leaderboard distance** and **Pace shown as**: the label and description sit above a
      full-width Metres|km / Split|Watts control.
- [ ] Notification switches are **blue** when on.
- [ ] **Log out** is blue; **Contact us** has no address under it; **Delete account** is its own
      card with centred red text; the version is centred at the bottom.
- [ ] The Review screen's "Include on leaderboards" switch is still **green** (as the canvas
      draws it) — say if you want it blue too.
